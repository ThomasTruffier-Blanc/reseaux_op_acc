# Site de révision — réseaux opérateurs et accès

Le site est statique : HTML, CSS et JavaScript, sans installation de dépendances.

Pour l’ouvrir localement, placez-vous dans le dossier extrait puis lancez :

    python -m http.server 8000

Ouvrez ensuite http://localhost:8000 dans un navigateur.

Fichiers principaux : index.html (structure), style.css (mise en forme), content.js (chapitres, glossaire, TD), practice.js et pon-practice.js (quiz, flashcards, exemples), app.js (navigation et interactions). Le dossier sources/ contient les PDF accessibles depuis le site.
